Folder di komputer

Isi file di server ini disinkronkan ke folder di profil pengguna tiap komputer, dicek tiap 10 detik. Hanya lewat LAN: komputer yang terhubung lewat internet (Cloudflare) tidak menyinkronkan. Folder dibuat otomatis bila belum ada. Kosongkan untuk mematikan fitur ini di semua komputer.

  • Terima saja: komputer mengikuti server. Hapus atau ubah file di komputer itu tidak berpengaruh ke server; file dikembalikan.
  • Kirim saja: perubahan dan hapus di komputer itu dikirim ke server (dan ke komputer lain yang menerima). Perubahan lain tidak diterima.
  • Dua arah: perubahan dan hapus di mana pun saling menyebar. Bila dua sisi mengubah file yang sama, yang terbaru menang.
